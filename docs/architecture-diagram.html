IT Help Chatbot — one namespace, four images, no external state

Every solid box runs in Kubernetes. The dashed group on the right is what you point the assistant at in Settings. Embeddings and reranking never leave the cluster — their model weights are baked into the images, which is what makes an air-gapped install possible.

request path data background work external / configured in Settings

Reading it: a question arrives over HTTPS; nginx serves the SPA and proxies /api; the backend classifies the domain, runs the guardrails, retrieves (pgvector + BM25 → reciprocal rank fusion → rerank), gates confidence, then streams an answer with citations. Background work — Confluence sync, Jira reconciliation, retention — runs on Celery, driven by beat.

It fails downwards: a dead reranker returns vector order, a dead provider returns an error the UI can show, a dead database turns /health red and the Overview says so. No path fabricates an answer.
